# YT2MP3 Downloader

Aplicación para Windows que guarda audio en **MP3** o vídeo en **MP4** a partir de un enlace de YouTube.

## Descargar

Ve a [Releases](../../releases/latest) y descarga el archivo `YT2MP3-Downloader_..._x64-setup.exe`.

- Se instala sin permisos de administrador.
- Al abrirla por primera vez te pedirá tu **clave de licencia**.
- Para actualizar: menú **⋮** → *Buscar actualizaciones*.

> Windows puede mostrar un aviso de SmartScreen ("Editor desconocido"). Pulsa *Más información* → *Ejecutar de todas formas*.

---

Este repositorio solo contiene los instaladores. El archivo `revocadas.json` lo usa la aplicación para desactivar licencias.
